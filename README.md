# Global Electronics Retailer Dashboard

## Overview

This personal project was created to strengthen my skills in Excel, Python, and Power BI by analyzing a global electronics retailer dataset from Maven Analytics. The project involved cleaning and preparing the data using 
Excel and Python, making business questions, and building a Power BI dashboard to communicate the key business insights. 

## Files

`Global Electronics Retailer Dashboard Payut.pbix` - Power BI file that contains the visualizations and reports

`Global Electronics Retailer.zip` - The dataset that I used for this project
